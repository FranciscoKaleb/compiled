Load 30 authors with their books

Result

AuthorBooks

The code that causes it

authors = session.execute(select(Author)).scalars().all()   # 1 query
for a in authors:
    print(a.name, [b.title for b in a.books])               # a.books → 1 query EACH

Nothing in that loop looks like a database call. The ORM makes one anyway, per author, the moment .books is touched. In a template, {% raw %}{% for book in author.books %}{% endraw %} is the same thing.
