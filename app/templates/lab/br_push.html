The browser will ask for permission. Then it contacts its vendor's push service and hands this server an endpoint URL plus encryption keys.

Send from the server

Requires internet: the browser subscribes with Google/Mozilla/Apple's push service and this server posts to it. Behind a strict firewall the subscribe step will fail.
