        {{ notes.section('The URL, part by part', [
            'https:// — the scheme: which protocol, and (for https) that TLS encrypts everything after the hostname, including the path and query.',
            'user@ — obsolete userinfo; browsers strip or block it because it was used for phishing.',
            'example.com:8443 — host and port. The port is omitted when it is the default (80 / 443). The host also travels as the Host header, which is how one IP serves many sites.',
