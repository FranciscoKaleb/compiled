Nothing failed; that is what makes it dangerous.', 'Optimistic: every save is UPDATE … SET balance=?, version=version+1 WHERE id=1 AND version=? with the version the editor read. Conflicts are rare, checking is free, no state to leak. Cost: when a conflict happens the user must reload and redo. Send the version to the client (a hidden field, an ETag) and back again.', 'Pessimistic when redoing work is expensive or impossible — a long document edit, a booking form, an admin fixing a record — and users expect "someone else is editing this".', 'Real databases have SELECT … FOR UPDATE, which locks the row inside a transaction.
