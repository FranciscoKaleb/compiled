One URL, negotiated

Every button requests exactly /api/basics/negotiate. Only the request headers differ.

Response

—

Headers you will meet daily

HostWhich site, on a server that hosts many. Mandatory in HTTP/1.1.
Content-TypeWhat the body is: application/json; charset=utf-8. Both directions.
Content-LengthBody size in bytes. Absent when streaming (chunked).
Accept / Accept-Language / Accept-EncodingWhat the client can handle. The server picks.
AuthorizationBearer <token> or Basic base64(user:pass). Never cached.
Cookie / Set-CookieThe session mechanism. Set-Cookie is hidden from JS.
Cache-Control / ETagCaching rules (Level 2).
LocationWhere to go: with 3xx redirects and 201 Created.
User-AgentWhich browser. Lies constantly; do not branch on it.
Origin / RefererWhere the request came from (CORS, CSRF checks).
VaryWhich request headers change the response — vital for caches.
X-Request-IdNot standard, universal anyway: trace one request through every log.
