Ask the server for a status

Each button requests /api/basics/status/<code>. The server answers with that code and whatever companion header the code calls for.

What came back

Pick a code.

—

The five classes

1xxInformational — "keep going". 101 Switching Protocols is the WebSocket handshake (Level 1). Rarely seen by application code.
2xxSuccess — it worked. 200 with a body, 201 for created, 204 for "done, nothing to say", 202 for "later".
3xxRedirection — the answer is elsewhere. 301/308 permanent, 302/307 temporary, 304 "use your cache".
4xxClient error — the request is the problem. Fix the request; retrying the same one will not help.
5xxServer error — the server is the problem. The request may be fine; retrying later may work.
