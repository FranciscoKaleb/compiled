Fetch the same document three ways

Cache-Control: no-store

Every click is a full round trip and a full body. The baseline.

ETag + If-None-Match → 304

The client remembers the ETag and asks "has it changed?". When it hasn't, the server answers 304 Not Modified with no body.

Cache-Control: max-age=10

For ten seconds the browser does not contact the server at all — the wire log shows nothing, and transfer size reads 0.

Bumps its version, so the next ETag revalidation comes back 200 with a new body.
