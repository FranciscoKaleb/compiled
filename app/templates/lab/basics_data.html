{{ notes.section('What you are seeing', [ 'Query string: the data rides in the URL. Spaces become + or %20, everything is a string, and age arrives as "36" not 36. Repeated keys (tags=math&tags=engines) become a list. Visible in logs and history — never for secrets or anything large.', 'application/x-www-form-urlencoded: the same encoding as the query string, moved into the body. It is what a plain HTML <form method="post"> sends. Still all strings, still flat.', 'application/json: types survive — 36 is a number, ["math","engines"] is a list — and nesting is free. One JSON.parse on the server. This is the default for APIs.', 'multipart/form-data: each field is a "part" with its own little headers, separated by a random boundary string. Verbose (look at the size), but the only encoding that carries a file alongside fields. Pick a file and compare.' ], 'accent') }} {{ notes.section('Choosing', [ 'Reading, filtering, paging → query string. It is bookmarkable and cacheable, which is the point of GET.', 'JavaScript talking to your own API → JSON. Flask reads it as request.form.', 'Anything with a file → multipart. With fetch, pass a FormData object and do not set Content-Type yourself; the browser must generate the boundary.', 'Large binary uploads → send the file as the raw body (Content-Type: image/png) or in multipart; never base64 inside JSON, which adds a third to the size and a parse of the whole thing into memory.' ]) }} {{ notes.section('Gotchas', [ 'JSON has no comments, no trailing commas, no single quotes, and no undefined.
